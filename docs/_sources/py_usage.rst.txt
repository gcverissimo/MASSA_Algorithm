Python usage (py_massa)
=======================

.. code-block:: python

    py_massa(
        file_input: str,
        working_directory: str,
        job_name: str = "MASSAoutput.sdf",
        extension_type: str = "svg",
        dendrogram_xfont_size: int = 5,
        barplot_xfont_size: int = 9,
        training_percent: float = 0.8,
        bioactivities_as_args: list | None = None,
        npcs: float | int = 0.85,
        svd_parameter: str = "full",
        linkage_method: str = "complete",
        flag_dendrogram: bool = True,
        splitting_strategy: str = "tt",
        drop_errors: bool = True,
        large_library: str = "auto"
    )

Run the MASSA Algorithm directly from Python.  
Equivalent to executing the command-line interface:

.. code-block:: bash

    MASSA_Algorithm -i <input_file>.sdf -o <output_file>.sdf


Parameters
----------

**file_input** : str  
    Path to the input file. Accepted formats: ``.sdf``, ``.mol``, ``.mol2``, ``.xlsx``, ``.xls``, ``.csv``.  
    The ``.sdf`` format is preferred.  

    **Notes:**
    - ``.mol2`` files are supported only if generated by *Discovery Studio Visualizer*.
    - For spreadsheet formats, MASSA searches for a column containing *smiles*.
    - Molecule names are extracted from columns: *Molecule name*, *Name*, *Molecule ChEMBL ID*, or *ID*.

**working_directory** : str  
    Directory where output files will be saved.

**job_name** : str, default="MASSAoutput.sdf"  
    Output file name or path. Recommended to use ``.sdf``.

**extension_type** : str, default="svg"  
    Image file extension. Suggested: ``png`` or ``svg``.

**dendrogram_xfont_size** : int, default=5  
    Font size for molecule labels in dendrogram plots.

**barplot_xfont_size** : int, default=9  
    Font size for cluster labels in bar plots.

**training_percent** : float, default=0.8  
    Proportion of molecules in the training set. Must be between 0 and 1.

**bioactivities_as_args** : list of str or None, default=None  
    List of biological activities or other Y-properties used for dataset splitting.  
    Example: ``["pIC50", "pMIC"]``.

**npcs** : float or int, default=0.85  
    Number of principal components for PCA reduction.  
    - If between 0 and 1, represents variance fraction retained.  
    - If ≥ 1, specifies exact number of PCs.  

    **Notes:**
    - If the number of PCs is an integer and equal to or greater than the number of physicochemical properties (7), the PCA step will be bypassed for this domain.
    - If biological activities < 3, PCA is bypassed.

**svd_parameter** : str, default="full"  
    Solver for PCA. See `sklearn.decomposition.PCA <https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html>`_.

**linkage_method** : str, default="complete"  
    Linkage criterion for hierarchical clustering.  
    Options: ``complete``, ``single``, ``ward``, ``average``, ``weighted``, ``centroid``, ``median``.  
    See `scipy.cluster.hierarchy.linkage <https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.linkage.html>`_.

**flag_dendrogram** : bool, default=True  
    Whether to generate dendrogram plots.

**splitting_strategy** : str, default="tt"  
    Strategy for data splitting.  
    - ``"tt"`` – training/test sets.  
    - ``"tt-val"`` – training/test/validation sets.

**drop_errors** : bool, default=True  
    Ignore chemistry errors and log them, instead of aborting execution.

**large_library** : str, default="auto"  
    Switch between hierarchical clustering and MiniBatch-KMeans for large datasets.  
    - ``"auto"``: use KMeans if ≥ 10,000 molecules.  
    - ``"true"``: force KMeans.  
    - ``"false"``: force HCA.


Examples
--------

.. code-block:: python

    from massa import py_massa

    py_massa(
        file_input="dataset.sdf",
        working_directory="./results",
        job_name="QSAR_split.sdf",
        bioactivities_as_args=["pIC50", "pMIC"],
        splitting_strategy="tt-val",
        npcs=0.9,
        linkage_method="complete",
        flag_dendrogram=True
    )


Notes
-----

- Image files are saved to a subfolder in the same directory as the output file.
- Using ``.sdf`` input is strongly recommended to prevent errors.
- For large datasets (≥10,000 molecules), set ``large_library="true"``.
